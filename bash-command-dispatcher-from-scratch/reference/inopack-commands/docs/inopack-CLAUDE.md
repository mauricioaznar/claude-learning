# INOPACK Claude adapter

Before working in this repository, run `inopack summary` (or `bash
scripts/inopack.sh summary` from the umbrella) and read
[docs/agent-instructions.md](docs/agent-instructions.md) completely. Then follow its
required reading order and treat the canonical documents it names as binding.

Use the tracked `inopack` commands for workflow operations. Do not replace them
with Claude-specific hooks, raw Git commands, or automatic commits.
